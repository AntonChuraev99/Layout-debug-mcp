## Выводы

Код в публичном репозитории, PR #1. Сервер слушает только loopback, запросы с чужих origin и rebinding-Host получают 403, запись чат-агента ограничена `projectDir`. Браузерный smoke на демо прошёл: выделение, drag, отправка правки в очередь. Встроенный агент на копии демо внёс правку в `index.html`, вызов `Agent` отклонён хуком. Попытку записи в `.claude/` вживую не увидели: после Edit агент висел больше 6 минут без вывода, причина не установлена. Отмены прогона из окна нет (R9 аудита). С заданной в окружении `ANTHROPIC_API_KEY` чат падает с 401, если ключ недействителен: SDK берёт ключ раньше логина подписки (источник: ответ `401 API key is invalid` в чате окна; без переменной тот же прогон авторизовался).

Осталось (в roadmap, не в этой задаче): чтение агента вне `projectDir`, prompt injection через текст страницы, `postMessage(..., '*')` из окна в iframe, Android-агент как библиотека с loopback-сокетом, установка одной командой, английский UI, CI.
